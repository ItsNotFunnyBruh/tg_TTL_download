# Telegram TTL Media Downloader

Скрипт для автоматического скачивания исчезающих медиафайлов (TTL) из Telegram.

## Описание

Этот скрипт отслеживает чат с указанным пользователем и автоматически скачивает все медиафайлы с ограниченным временем просмотра (TTL - Time To Live) до их исчезновения.

## Функциональность

- **Автоматическое обнаружение** TTL медиа (фото, видео, документы)
- **Мгновенное скачивание** до истечения времени жизни
- **Организация файлов** по папкам пользователей
- **Поддержка всех типов** медиа с TTL
- **Логирование процесса** в консоль

## Использование

После запуска скрипт будет:

1. Отслеживать все новые сообщения в чате с указанным пользователем
2. Автоматически определять медиафайлы с TTL
3. Мгновенно скачивать их до исчезновения
4. Сохранять в папку download/ID_пользователя/
